A Community project that revives the experience of the original Windows Store on Windows 8.1: the Metro aesthetic running on an entirely new backend.

What is OctoStore

OctoStore is a 8Store Fork that has some new features that makes it even better. It tries to continue the same goal 8Store had, with the same passions.

Every app details page loads descriptions, categories, publisher, reviews and more from a JSON/PHP backend, while keeping the panel-based aesthetic that defined Windows 8.1 intact.

Right now it has a ot of features; You can manage your downloaded appx files, you can sign in into your OctoLive account and a lot more that you can discover by yourself!
